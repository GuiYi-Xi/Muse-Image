# GPT Image 2 电脑开发版 v1.0

## 直接使用（Windows 10/11）

1. 将整个 ZIP 解压到普通文件夹，不能在压缩包预览窗口内运行。
2. 双击 `START_WINDOWS.cmd`。
3. 浏览器会打开本机地址 `http://127.0.0.1:8765/index.html`；端口被占用时自动尝试 8766–8785。
4. 第一次使用，在右上角 `⋯` 设置 Base URL 与 API Key。凭据只保存在当前浏览器本机存储中，发行包未预置任何接口配置。
5. 使用期间保持启动窗口开启，结束时按 `Ctrl+C`。

无需安装 Python、Node.js 或其他运行环境，也不需要管理员权限。

## 已迁移功能

- 文生图、传图改图；改图支持最多4张参考图及图一/图二/图三/图四角色说明。
- 文生图和改图可连续加入统一并行任务队列。
- 每项任务独立计时、取消，并显示成功/失败/取消状态。
- 文生图、改图各自独立输出尺寸和质量；改图包含 Auto、4:3、3:4。
- 内置提示词库；支持新增、编辑、删除最多100条本机自定义预设。
- 浏览器 IndexedDB 用于快速读取历史记录，长期文件保存在应用目录旁的 `output` 文件夹。
- 可在设置中指定本机历史储存文件夹；图片按项目分目录保存，并可从文件夹恢复历史记录。
- 宽屏双栏电脑布局，手机窄屏布局仍保留。

## 继续开发

- 主界面与业务代码：`index.html`（HTML、CSS、JavaScript 均在单文件中）。
- Windows 本地静态服务/API代理：`portable_server.c`。
- Logo：`muse-logo.png`。
- 修改 `index.html` 后，刷新浏览器即可看到效果，不需要重新编译 EXE。
- 只有修改 `portable_server.c` 时才需要重新编译 `GPT_Image_Server.exe`。

Linux 下编译命令：

```bash
x86_64-w64-mingw32-gcc -O2 -Wall -o GPT_Image_Server.exe portable_server.c -lwinhttp -lws2_32 -lshell32 -luser32
```

服务端强制上游 HTTP/1.1，并允许最长20分钟响应；每个本地请求使用独立线程，因此多个生图/改图请求可真正同时等待上游返回。付费生成请求不会自动重试。

## 数据与安全

- 包内 Base URL、API Key 均为空。
- 配置与提示词预设保存在浏览器本机；作品历史默认同步到应用目录旁的 `output`，浏览器 IndexedDB 只作为快速读取缓存。
- 选择历史储存文件夹后，应用会在其中保存 `projects.json`、项目目录、`records.json` 和 PNG 原图；清除浏览器数据后可在设置中重新授权并点击“从文件夹恢复”。
- 目录授权属于当前浏览器；更换浏览器、重装浏览器或移动历史目录后，需要重新选择目录。
- 不要将填过密钥的浏览器用户数据目录或截图公开。
- 服务仅监听 `127.0.0.1`，不会作为局域网公开服务。

## 已知边界

- 关闭启动窗口、关机或关闭页面会中断正在等待的任务。
- 实际并发上限还会受接口网关限流、网络、内存与图片大小影响。
- 本包是便携开发版，不是 Microsoft Store 安装包。
